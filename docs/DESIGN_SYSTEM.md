# Design System Nirava MIDI proposal

Stage1, belum desain/implementasi final. Workspace sederhana: parameter panjang/seed/temperature, tombol generate, status yang dapat dibaca screen reader, note-grid/event summary dan download .mid. Jangan menampilkan waveform/noise metrics atau audio A/B sebagai produk aktif. Output simbolik tidak otomatis bisa dimainkan elemen audio browser.

Keyboard focus/labels/contrast dan mobile layout wajib, error bisa ditindaklanjuti, seed/model/tokenizer version/termination reason transparan. Tidak ada rating/testimoni/angka musik fiktif. Tidak memakai tagline speech lama. Identitas Nirava tetap; palette/font lama hanya referensi opsional yang perlu review/lisensi, bukan tugas akademik utama. Audio renderer, animasi3D dan marketing landing page di luar MVP.
